# glixo-community-modules

Community **extensions** for Glixo — catalog samples, bundled first-party providers, and integration services.

Public product language is "extensions"; `service`, `extension`, and `component` are implementation roles declared inside `glixo.module.json`.

See `glixo-platform/docs/architecture/GLIXO_PLATFORM_EXTENSION_SYSTEM.md`.

## Layout

```
bundled/                 Preinstalled first-party providers (Anthropic, OpenAI, CLIProxy, Ollama)
catalog/
  code/                  Glixo Code extension samples (marketplace)
  agxos/
    apps/                Agxos app contributions
    extensions/          Agxos session extension contributions
integrations/teams/      Active Teams service (alpha)
packages/                Shared auth packages for integrations
archive/                 Retired stub manifests (not in catalog)
```

## Pack artifacts

After editing a catalog extension:

```powershell
cd glixo-community-modules
node scripts/pack-catalog-artifacts.mjs
cd ../glixo-dev-portal
npm run catalog:sync
```

## Capture catalog screenshots

With `dev.cmd` running (8103 / 33103 / 5180):

```powershell
cd glixo-community-modules
node scripts/capture-catalog-screenshots.mjs
node scripts/pack-catalog-artifacts.mjs
cd ../glixo-dev-portal && npm run catalog:sync
```

Use `E2E_HEADED=1` to watch Playwright. Optional mockups for theme work: `design/theme-references/`.

## Bundled providers

Ship preinstalled via `BundledProviderSeeder` in Glixo Code Server. They appear on **extend.glixo.io** as browse-only entries (configure API keys in Settings → Models; not installed from the marketplace zip):

- `bundled/anthropic` → `glixo.providers.anthropic`
- `bundled/openai` → `glixo.providers.openai`
- `bundled/cliproxy` → `glixo.providers.cliproxy`
- `bundled/ollama` → `glixo.providers.ollama`
