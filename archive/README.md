# Archive

Retired **design stubs and extraction notes** — not synced to the public marketplace catalog.

| Area | Contents |
|------|----------|
| `services/` | Early messaging/work integrations (Gmail, Outlook, Jira, …) kept for reference |
| `extensions/` | UI-only extension sketches that depended on unfinished services |

These manifests may contain `dev-placeholder` artifact hashes and `0.0.0-stub` versions. Do not install from here for production use.

Active catalog samples live under [`catalog/`](../catalog/). Bundled first-party providers live under [`bundled/`](../bundled/).
